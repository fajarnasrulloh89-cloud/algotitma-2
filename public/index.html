Estimasi Time Complexity

  • Tambah data mahasiswa: O(n) karena cek duplikasi NIM/email.
  • Tampilkan semua data: O(n).
  • Linear/Sequential Search: O(n).
  • Binary Search: O(log n) setelah data diurutkan.
  • Bubble/Selection/Insertion Sort: O(n²).
  • Merge Sort: O(n log n).
  • File I/O baca/tulis JSON: O(n) terhadap jumlah data.
